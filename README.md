clippings is a no-bullshit, lightweight, and simple clipping software for Windows 11.

**NOTICE: THIS PROJECT IS VIBECODED.** I wanted to test it out and make something simple but very useful.

## Features

- **Instant replay** — Keep a rolling buffer of your screen and save the last few minutes with a customizable hotkey.
- **Clip library** — Play, rename, trim, duplicate, and delete saved clips in the app.
- **Video settings** — Pick a monitor and a quality preset, or set your own resolution, frame rate, and bitrate. Hardware encoding is available on supported GPUs.
- **Audio controls** — Choose your desktop audio and mic devices, adjust their levels, and test your mic before recording.
- **Tray controls** — Start or stop the replay buffer from the system tray.
- **Save feedback** — Pick a custom sound to play when clippings accepts a save.
